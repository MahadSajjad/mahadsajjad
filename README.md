## Rendering and performance

Phones, touch devices, narrow viewports, and reduced-motion users get native scrolling, static gradient backgrounds, a swipeable project gallery, and static stack chips. Decorative WebGL effects and the physics engine load only on desktop devices with a fine pointer and no reduced-motion preference. Desktop shader, gallery, and physics effects pause when hidden or outside the viewport; the fluid cursor loads on pointer movement and stops rendering when idle. The original “Tools I build with” carousel and theme-switching animation are preserved.

Use `npm run build` followed by `npm start` to evaluate production loading and scrolling. `npm run dev` includes development tooling and compilation overhead.

If a hydration warning shows extra `bis_skin_checked` attributes, a browser extension modified the HTML before React hydrated it. Disable the injecting extension for the site and reload, or verify in a clean browser profile with extensions disabled. These attributes are not generated by this application. See the [Next.js hydration troubleshooting guide](https://nextjs.org/docs/messages/react-hydration-error).
